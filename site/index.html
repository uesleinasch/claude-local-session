Plugin open source para o Claude Code

Suas sessões do Claude Code no celular.

Cada sessão vira uma página na sua rede local. Mande prompts, acompanhe o que o Claude está executando, responda às perguntas dele e aprove ou negue comandos, sem voltar para o computador.

O que dá para fazer pelo celular

  • Conversar com a sessão

    Mande prompts para qualquer sessão aberta e leia as respostas em markdown. O que você digita no terminal também aparece, então dá para começar no computador e continuar no celular.

  • Aprovar com contexto

    Os pedidos de permissão chegam com a operação inteira: o comando, o diff ou o arquivo. Você permite ou nega de onde estiver, e o auto mode aprova sozinho quando você confia na tarefa.

  • Responder perguntas

    Quando o Claude pergunta, as opções aparecem como cartão na página. A resposta volta para a sessão como se você tivesse digitado.

  • Ver o que está rodando

    Uma régua mostra cada ferramenta e o alvo, enquanto roda. Ao lado ficam o uso da janela de contexto e o modelo ativo.

  • Abrir sessão nova

    Navegue pelas pastas, marque favoritas, copie, baixe arquivos e inicie uma sessão do Claude no projeto que quiser.

  • Terminal de verdade

    Um shell no diretório do projeto, pelo navegador. Ele roda num tmux, então sobrevive se a página ou o hub caírem.

  • Avisos e fotos

    Notificações pelo ntfy quando uma sessão pede você ou termina. Também dá para mandar foto da câmera direto para o prompt.

  • De qualquer lugar

    Funciona na rede local e, com o Tailscale, de qualquer lugar. O app Android acha o hub sozinho depois de parear uma vez pelo QR code.

Como funciona

Um hub roda na sua máquina e atende a página na porta 7777. Cada sessão do Claude Code se conecta a ele por um servidor MCP do plugin, e os hooks contam ao hub o que está acontecendo. O canal oficial do Claude Code leva os seus prompts até o modelo.

Nada sai da sua rede: não há servidor na nuvem nem conta para criar. Quem tem o link com o token entra; sem o token, o hub responde 404, como se não existisse.

Instalar

  1. Baixe e instale o pacote

    No Debian ou no Ubuntu, pegue o .deb da última release:

    gh release download --repo uesleinasch/claude-local-session --pattern '*.deb'
sudo apt install ./local-session_*_amd64.deb

  2. Configure a sua conta

    Registra o plugin no Claude Code, liga o canal e sobe o serviço do hub:

    local-session setup

  3. Abra o link no celular

    Inicie o claude num projeto e abra o link com o token. Ele aparece na janela do Local Session, no menu de aplicativos, junto com um QR code.

Em outra distribuição Linux, use o instalador. O app Android se baixa pela página do app, aberta no celular.

Segurança, sem rodeio

A página aprova comandos Bash, então o link vale tanto quanto uma senha. Toda requisição exige o token, os caminhos são conferidos contra a sua home e as pastas permitidas, e as teclas enviadas ao terminal passam por uma lista fechada. O tráfego na rede local é HTTP: para usar de fora, use a tailnet. Os detalhes estão no SECURITY.md.

In English

Local Session is a Claude Code plugin that puts every session on a web page in your local network. From your phone you can send prompts, follow what each session is running, answer its questions and approve or deny permission requests. It ships as a Linux package with a tray app, plus an optional Android client, and works over Tailscale when you are away. The project is written and documented in Brazilian Portuguese, but issues and pull requests in English are welcome. MIT licensed.
